## 2. 改变 v2 设计的四个事实

1. **CPU 不是 10ms 硬线**：Free 弹性机制下生产 46–57ms 的 get-session 稳定存活；但弹性不可当预算——持续超限会终止。升级 Paid（$5/月）是消除该风险的唯一途径，列为 M8 前 owner 权衡项。
2. **冷路径地板 ~470ms 且平坦**：isolate 冷启动 + D1 连接的固定开销，闲置 1 小时不变。M2 的 TTFB<100ms 目标限定热路径（cookieCache 命中）；冷场景目标 <600ms。
3. **D1 本体很快、挂起是平台间歇现象**：新库全部查询 ≤485ms wall；生产 504 式挂起（wall 30s+/cpu 1-6ms）未在新库复现，生产近 24h 也零挂起。5s safeReadTimeout 快速失败保留为 v2 设计（防御间歇性）。
4. **`Date.now()` 在纯计算期间冻结**：v2 一切耗时测量用平台日志 cpuTime 或跨 I/O 边界计时。
